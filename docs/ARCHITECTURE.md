# Architecture

## Flow

```
Option+D (Carbon hotkey, KeyboardShortcuts)
   │
   ▼
PanelController.toggle()
   │  remember previous app (NSWorkspace.frontmostApplication)
   │  SelectionReader: AX selected text ─▶ fallback simulated Cmd+C (≤120 ms, clipboard restored)
   ▼
TranslatorPanel (NSPanel, pre-built, non-activating) shows PanelView
   │  text changes ─▶ PanelModel: 250 ms debounce, cancel previous task
   ▼
EngineRouter.translate(text, pair, configuration)
   ├─ Google  : GoogleCloudEngine (v3 or v2 REST, API key header)
   ├─ DeepL   : DeepLEngine (v2 REST, free/pro host by key suffix)
   ├─ Apple   : AppleEngine (TranslationSession, installed models)
   └─ Auto    : Google ─▶ DeepL ─▶ Apple; cloud engines only with a key,
                skipped on offline / error / 1.5 s timeout (D32)
   ▼
TranslationResult(text, engine) ─▶ result pane + engine badge
   │
   ├─ Enter      : copy, hide
   └─ Cmd+Enter  : hide, activate previous app, simulated Cmd+V, restore clipboard
```

## Layout

```
Translator/
  App/        TranslatorApp (@main, MenuBarExtra), AppDelegate (startup, hotkey, Settings window), AppSettings (UserDefaults),
              AppFlavor (dev vs release, D33)
  Panel/      TranslatorPanel (NSPanel subclass), PanelController (show/hide, placement, previous app, resize),
              PanelModel (state, commands, debounce, keyboard routing, overlay lists)
  Views/      PanelView (SourcePane, TranslationPane, LanguageSelector, SwapButton, FooterBar), Overlays (LanguagePicker Cmd+P,
              ActionPanel Cmd+K), Settings/ (SettingsView tabs, SettingsWindowController)
  Engines/    TranslationEngine protocol, EngineRouter, GoogleCloudEngine, DeepLEngine, AppleEngine
  Services/   LanguageCatalog (+ Recents), FuzzyMatcher, SelectionReader (+ KeySimulator), PasteService
              (+ PasteboardSnapshot), SpeechService, LoginItem, AppUpdater
  Resources/  Info.plist (generated by XcodeGen from project.yml), Assets.xcassets (AppIcon)
TranslatorTests/  EngineTests (request/response parsing, router), ServiceTests (fuzzy, catalog, settings, model keys)
```

## Engines

```swift
protocol TranslationEngine: Sendable {
    var id: EngineID { get }
    func translate(_ text: String, from source: Language, to target: Language) async throws -> String
}
```

- `GoogleCloudEngine` (D30): v3 `POST https://translation.googleapis.com/v3/projects/{project}:translateText` with `contents`, `sourceLanguageCode`, `targetLanguageCode`, `mimeType=text/plain`; or v2 `POST …/language/translate/v2` with `q`, `source`, `target`, `format=text`. The key travels in the `x-goog-api-key` header. Request building and response/error parsing are pure functions, tested with canned JSON.
- `DeepLEngine` (D31): `POST https://api[-free].deepl.com/v2/translate`, `Authorization: DeepL-Auth-Key`, JSON `text[]`, `source_lang`, `target_lang`. Code mapping (`sourceCode`, `targetCode`) and parsing are pure and tested.
- `AppleEngine`: `TranslationSession(installedSource:target:)` (macOS 26+). Only installed models; downloads are triggered from Settings via `.translationTask` + `prepareTranslation()`. `LanguageAvailability` tells which pairs are installed and which languages get the on-device mark in the picker.
- `EngineRouter`: `plan(for:)` turns the mode + configured keys into an ordered engine list, `shouldFallBack(after:)` decides whether Auto moves on, and cloud engines race a 1.5 s timeout (D32). All pure and tested with stub engines.
- Languages are Google codes everywhere (`LanguageCatalog`); each engine maps them to its own codes.

## Panel

- Built once in `applicationDidFinishLaunching`, hidden with `orderOut`, shown with `makeKeyAndOrderFront` (no app activation) on the hotkey path (D4).
- `.nonactivatingPanel`, `.floating` level, `canBecomeKey = true`, joins all Spaces and full-screen apps.
- Dismissed on Esc and on `resignKey` (click outside) unless pinned (D5).
- `NSGlassEffectView` is the panel's content view (Liquid Glass, rounded corners); the SwiftUI `PanelView` sits inside it in an `NSHostingView` (D12). Controls inside are plain (Raycast look): no glass buttons, two tinted cards, language selector as text + chevron in each card header.
- Keyboard: `TranslatorPanel.sendEvent` hands every key-down to `PanelModel.handleKey` first. It consumes Esc, Enter, Cmd+Enter, Cmd+K/P/Shift+P/./S/, and, when an overlay is open, arrows and Enter; everything else reaches the SwiftUI text editor (Shift+Enter inserts a newline).
- Overlays (`LanguagePicker`, `ActionPanel`) are SwiftUI views over the panes, bottom-right; their list state (`overlayQuery`, `overlayIndex`) lives in `PanelModel` so keys and clicks share one path.
- Previous app + selection: on the hotkey path the AX read is synchronous; if the focused element has no selection attribute, a simulated Cmd+C runs **before** the panel takes key focus (bounded to ~120 ms, clipboard restored), otherwise the keystroke would land in the panel.

## Storage

- `UserDefaults` only (D26): language pair, recents, engine mode, Google API key + API version + project ID, DeepL API key, layout, panel size, menu bar toggle. Hotkey stored by `KeyboardShortcuts`; launch-at-login state read from `SMAppService`; Sparkle keeps its own.

## Updates

- Sparkle 2 (`SPUStandardUpdaterController`), feed `https://github.com/betty2310/translator/releases/latest/download/appcast.xml` (D21). Release builds are signed with the self-signed certificate (D16); the appcast is EdDSA-signed in CI.
